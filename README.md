# 🏛️ ધી જૂનાગઢ કોમર્શીયલ કો-ઓપરેટીવ બેંક લી. - ગોલ્ડ લોન પોર્ટલ
## JCCB Gold Loan Portal (100% Offline Standalone Local PC Tool)

આ એપ્લિકેશન ગોલ્ડ લોન એન્ટ્રી, ગણતરી અને વાઉચર પ્રિન્ટિંગ માટે બનાવવામાં આવેલ **સંપૂર્ણ લોકલ (Client-side / Localhost) સિસ્ટમ** છે. આ એપ્લિકેશન કોઈપણ ક્લાઉડ (Zero Firebase / Zero Cloud) વગર **૧૦૦% ઇન્ટરનેટ વિના (Air-Gapped)** દરેક શાખાના પોતાના લોકલ કમ્પ્યુટરમાં ચાલે છે. તમામ લોન એન્ટ્રી, ગ્રાહકના ફોટા અને રેકોર્ડ્સ તમારા કમ્પ્યુટરના **IndexedDB & LocalStorage** માં સુરક્ષિત સંગ્રહિત થાય છે.

---

### 🚀 કેવી રીતે શરૂ કરવું? (How to Run on Local PC)
૧. **`start_local_gold_portal.bat`** ફાઇલ પર ડબલ-ક્લિક કરો (અથવા `index.html` ફાઈલ બ્રાઉઝરમાં ખોલો).
૨. તે બ્રાઉઝર (Google Chrome, Microsoft Edge અથવા Mozilla Firefox) માં તરત ખૂલશે.
૩. **સેન્ટ્રલ મેનેજમેન્ટ પોર્ટલ** ખોલવા માટે `open_management_portal.bat` પર ડબલ-ક્લિક કરો.

### 💾 ડેટા સેવિંગ & બેકઅપ (Local PC Storage & Backup)
- **લોકલ સ્ટોરેજ**: તમામ લોન, ગ્રાહકના કેવાયસી ફોટા અને સેટિંગ્સ તમારા બ્રાઉઝરના IndexedDB સ્ટોરેજમાં સેવ થાય છે.
- **બેકઅપ ડાઉનલોડ**: કોઈપણ સમયે "Settings / Backup" માં જઈને તમારા કમ્પ્યુટર અથવા પેન ડ્રાઇવમાં `.json` અથવા `.xlsx` બેકઅપ ફાઈલ સેવ કરી શકો છો.
- **રીસ્ટોર**: નવું કમ્પ્યુટર બદલતી વખતે બેકઅપ ફાઈલ સરળતાથી રીસ્ટોર કરી શકાય છે.

### 📁 ફાઈલ માળખું (File Structure)
- `index.html` - મુખ્ય ગોલ્ડ લોન પોર્ટલ (Main UI)
- `firebase-config.js` - લોકલ સ્ટોરેજ ડેટાબેઝ એન્જિન (`LocalDBService` - 100% Offline)
- `app_gold.js` - કોર બેંકિંગ લોજીક, કેલ્ક્યુલેશન્સ & વાઉચર જનરેટર
- `management.html` & `management.js` - સેન્ટ્રલ મેનેજમેન્ટ & ઓડિટ કન્સોલ
- `start_local_gold_portal.bat` - ગોલ્ડ પોર્ટલ લોન્ચર
- `open_management_portal.bat` - મેનેજમેન્ટ પોર્ટલ લોન્ચર
